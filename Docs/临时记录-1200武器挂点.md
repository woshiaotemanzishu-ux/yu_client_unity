# 1200 武器挂点记录（2026-07-15）

本文件记录 1213/1200 第一套新武器的排查、误判修正和最终落地规则。正式交付规则见
`Docs/美术交付规范-角色部件.md` 和 Art 项目 `Assets/Editor/角色武器挂点模板.md`。

## 一、最终根因

这次不是单独一侧的问题，而是角色和武器各有一个错误：

1. **角色侧把腕骨原点误当成手心。** 之前自动补的 `rhand` 位于 `Bip001 R Hand` 下，局部变换为
   `position(0,0,0) / rotation(0,0,0) / scale1`。它会稳定跟随动画，但位置仍是腕骨原点，不能据此证明握持正确。
   对 1213 蒙皮网格按右手及手指骨权重烘焙测量后，手掌握持中心取为
   `position(-0.14,0.03,0.02) / rotation(0,0,0) / scale1`。
2. **武器侧丢失了原 FBX 的握持轴。** 1200 内已有 `Bone_wq_r`，相对武器根为
   `position(0,0,0) / rotation(0,0,89.71) / scale1`。旧模板工具却把 `weapon_attach` 强制清成单位旋转；
   同时旧版 `AttachmentSocketAligner` 只把定位器位置推到 `rhand`，没有解算定位器旋转，所以剑尖方向仍然相反。

1200 原 prefab 根位移 `(0.9067,-1.10961,-0.98606)` 只用于武器单独预览，不是握点或单位补偿，正式模板继续丢弃。

## 二、已落地方案

- Art 角色批处理把 1213 全部 7 个动作 prefab 的 `rhand` 统一烘焙到手掌中心
  `(-0.14,0.03,0.02)`；这是**每套角色骨架一次性校准**，不是每把武器单独调参。
- Art 武器批处理把 1200 的 `weapon_attach` 对齐原 FBX `Bone_wq_r`，保留其真实握点位置和轴向；
  `weapon_attach` 允许局部 position/rotation，唯独 scale 必须为 1。
- 运行时 `AttachmentSocketAligner` 现在同时对齐 locator 的位置和旋转：先用 locator 相对武器根的轴向反解武器根旋转，
  再把 locator 位置平移到 `rhand`。因此配置层仍保持 position `(0,0,0)`、rotation `(0,0,0)`、scale `1`。
- 1213 的 7 个动作和 1200 武器已通过资产管理的正式“导入/替换新模型”链路同步主工程。
- 缺 `weapon_attach` 的旧武器仍可临时按 prefab 根挂接并报警；此兼容只保护旧货，不能作为新交付标准。

## 三、验收结果与误判说明

正式导入后的静态检查：

- `attack/create3/death/idle/run/test/walk` 的 `rhand` 均为
  `parent=Bip001 R Hand, position(-0.14,0.03,0.02), rotation(0,0,0), scale1`。
- 1200 `weapon_attach` 为 `position(0,0,0), rotation(0,0,89.71), scale1`。
- 使用正式运行时对齐器后，locator 到 socket 的位置误差为 `0`（编辑器独立实例抽查曾见最大约 `0.0000014`），
  旋转误差为 `0°`，武器根反解为约 `Z=270.29°`。
- 游戏画面正面检查中，剑尖已由错误的向上改为向左下，护手落在右手掌附近，与原效果图的持剑方向一致。

此前在 `idle/create3/run/attack` 多时刻测得的“位置误差接近 0、角度误差 0”只能说明**错误变换很稳定**；
它比较的是 locator 与当时错误的腕骨原点，不能证明握点在手心，也不能证明剑的视觉轴向正确。以后验收必须同时包含：

1. locator 与 socket 的数值误差；
2. 手掌网格与护手/握柄的视觉关系；
3. 正面、背面、左右侧的剑尖方向；
4. 多动作和多个采样时刻是否脱手或跳位。

## 四、后续武器规范

- 新武器从 `Assets/Weapon/_Template/WeaponAttachmentTemplate.prefab` 开始，在 3D/Art 阶段把
  `weapon_attach` 放在握柄中心并对齐标准握持轴；导出前 Reset XForm。
- 同一骨架只归一一次 `rhand`；同一武器只定义一次 `weapon_attach`。角色动作和武器外观不能互相承担校准补丁。
- 静态武器只交付 `idle`，由程序在角色各动作复用；只有武器自身确有动画时才增加动作 prefab。
- 新角色骨架若手骨原点或轴向不同，修该角色模板的 `rhand`；新武器若握柄中心或轴向错误，修该武器的
  `weapon_attach`，不把问题转成 `model_replacement.json` 中逐角色、逐武器组合的固定偏移。
