## 每轮铁流程
1. 探测编辑器:`tasklist /FI "IMAGENAME eq Unity.exe"`。
2. 从下方队列取当前项(或继续上轮未完项),读老端对应 TS + ClientProtocol.json 摘 schema。
3. 实现:沿用既有三件套模式(Model/Controller/View + ControllerHub 接线 + csproj 手动补行)。
   - UI 无 prefab 时:写 UiCreator(布局归 prefab,C# 不写位置/尺寸;快照驱动,参照 Docs/UI模块SOP.md)。
   - 编辑器占用时 UiCreator 只写代码,prefab 生成挂入「待批处理」清单,编辑器空闲轮补跑。
4. 验证(必须,不通过不 commit):
   - 编辑器占用:`dotnet msbuild`(新文件手动插 csproj)0 错误。
   - 编辑器空闲:`Unity.exe -batchmode -projectPath . -executeMethod Shenxiao.EditorTools.CliVerify.<Case> -logFile Temp/cliverify_<case>.log`,新系统必须配新 Case(合成包驱动断言),EXIT 0。
5. 提交:逐文件 add(只加本轮自己动过的文件)→ commit(中文一句话,说清协议号与系统)。
6. 在本文件「进度日志」追加一行;更新队列状态。
