# 人物与设置面板对标：经验与排障

> 状态：生效  
> 最后核对：2026-07-29

## 1. 适用范围

本文覆盖 `RoleModule/EquipmentView` 与 `SettingModule/SettingView` 的老端对标、动态列表布局、资源复原和功能验收。老端事实源依次为：`http://127.0.0.1:8091/` 运行态、Laya `.scene`、业务 TypeScript；Unity 侧以 Creator 生成的 Prefab 和真实 `BaseView.Show()` 运行态为准。

## 2. 已确认的根因

### 2.1 设置页“整体像错位/错版”

问题不是 652×936 主面板坐标整体错误，而是两类问题叠加：

1. `Assets/GameRes/resource/game/setting/texture` 缺少老端原始图片，且若干同名 PNG 实际内容被错误资源占用。例如 `ui_button_rect8.png` 被导成圆形刷新图，正确资源应是“更换头像”红色横条；`ui_button_rect5.png` 被导成圆形“基本设置”，正确资源应是页签底图。
2. 旧快照把 `change_head_btn` 和 `_btn_copy` 误取成内部小图的结算尺寸。老端 `.scene` 与当前运行态的最终值分别是 `125×37`、`100×34`，文字必须可见。

排查设置页时，应先直接查看 PNG 内容和 `.scene` 的 `skin`，不能只看文件名、GUID 或 RectTransform。

### 2.2 真机上偶发纵向错位

旧实现由 `SettingView.ReflowBaseBlocks`、`PlaceShieldItem` 和 `EquipmentView.EnsureAttrItems` 在运行时写 `anchoredPosition/sizeDelta`。这会让转换坐标、Canvas 缩放和代码二次布局同时生效，编辑器与真机容易出现不同结果。

当前约定：

- 设置页五个动态分块使用 Prefab 内 `VerticalLayoutGroup + ContentSizeFitter`；每个分块放在独立 Row 中，横向偏移由 Creator 固化，运行时只显隐 Row。
- 自动拾取、屏蔽列表和人物属性列表使用 Prefab 内 `GridLayoutGroup + ContentSizeFitter`；运行时只克隆、填数据和显隐。
- 人物战力项由 Prefab 内 `HorizontalLayoutGroup` 居中。
- 禁止在上述 View 的刷新逻辑中重新计算面板坐标。

## 3. 人物面板功能口径

- 基础属性按老端顺序展示 13 项：攻击、生命、破甲、防御、命中、闪避、暴击、坚韧、元素攻击、元素防御、绝对攻击、绝对防御、移动速度。
- “基础属性/极品属性”按钮必须切换标题和列表；极品属性顺序按老端 `spe_show_index`，百分比值按协议的万分比数据除以 100 后显示 `%`。
- 普通属性显示原始整数，不能用“万/亿”缩写；等级经验与战力可继续使用各自既有格式。
- 已有真实模块的入口直接打开：技能标签、时装、套装收集。尚未迁移 UI 的成就、勋章、称号、属性药剂、名誉等入口必须走统一路由占位提示，不能静默无响应或伪造业务页面。
- 世界等级说明层默认隐藏，由世界等级按钮打开，点击说明底板关闭。

## 4. 设置面板功能口径

- 四滑条读取 10202/10203 的同屏人数、特效数量、音效、音乐；拖动即时影响本地显示/音量，关闭面板时批量上报。
- 自动拾取与屏蔽项按 `config_setting.json` 顺序和默认值生成，点击发 10203；屏蔽页为两列 10 项。
- 坐骑、降神、自动任务按功能开放和服务端设置显隐，隐藏分块必须由布局系统自动收拢。
- 改名、复制 ID、切换角色、返回登录、还原默认、脱离卡死、修复异常、关闭和两个页签均必须有真实点击链。
- 头像、完整按钮、分区标题纹、底部五钮、页签必须使用 setting 目录的老端原图，不得用同名占位图替代。

## 5. 生成与验收

- 设置页生成入口：`SettingCreator.Generate()`。
- 人物页布局装配入口：`RoleEquipmentCreator.Generate()`；它只升级既有 `RoleModule.prefab`，不会重转整棵 Laya 树。
- 静态验收至少核对：根尺寸、顶部/底部/页签坐标、Grid/VerticalLayout 组件、标题默认显隐、PNG 实际内容。
- 运行态验收必须经过真实 Prefab 的 `Show()`，分别截图设置基础页、设置屏蔽页和人物页；仅看 Scene/Prefab 预览不算通过。
- 重点回归 720×1280 与真机长宽比，确认分块显隐、两列列表、按钮命中和弹窗层级不会随分辨率漂移。
