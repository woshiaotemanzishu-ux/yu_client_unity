# ArtImport 美术成品模型导入 — 使用说明

> 菜单:**神霄/美术/导入外部成品模型(保GUID)**
> 代码:`Assets/Editor/ArtImport/ArtPrefabImporter.cs`(+`ArtImportTextureTools.cs`)
> 台账:`Assets/Editor/ArtImport/ArtImportLedger.json`(每次导入的逐文件记录,窗口里"打开台账")

把美术工程(现行 `E:\Project\ArtsProject`)里的**成品 prefab**(模型+动作+特效自包含,如创角整模
`1111@create2.prefab`)连同全部依赖搬进主工程。两边 Unity/URP/Timeline 版本一致,资产连 `.meta`
原样拷贝(**GUID 不变**),所有引用自动接上;同一资产再次导入=原位替换,老资源不受影响。

## 日常用法:创角职业对照面板(左=老,右=新)

打开窗口,顶部就是对照表:**每个职业一行**(按 configlogin.json 的 CreateRole 职业表),
左边老拼装模型状态,右边新整模状态 + 美术工程交付状态:

```
剑士(1111)   老:拼装✓   新:create2+3   美术:已是最新   [导入/更新] [重导FBX]
武姬(1213)   老:拼装✓   新:未导入      美术:未交付     [导入/更新] [重导FBX]
```

- "美术工程"路径默认 `E:/Project/ArtsProject`(记住的),点 **[扫描]** 刷新;
- **[导入/更新]**:把该职业在美术工程 `role_{res}/` 下的成品 prefab 连依赖导入/替换(哈希比对,
  没变的跳过);
- **[重导FBX]**:强制重导该职业已导入的模型文件——**白模就点它**(FBX 内嵌材质的贴图是导入时
  按名搜索的,首轮批量导入 FBX 可能先于贴图导致搜索落空;新版工具导入时已自动做二次导入);
- **运行时规则(已接好):有新用新,没新用老**,单个职业替换不影响其他职业。

## 完整流程(选任意 prefab/文件夹)

下半部分:[添加 prefab…]/[添加文件夹…] → **[1. 扫描]**(只读,出新增/替换/未变/去重分类和警告)
→ **[2. 导入]**。

## 选项

| 选项 | 默认 | 说明 |
|---|---|---|
| 渲染模式 | 独立渲染器 | prefab 根挂 `ArtModelRenderProfile`;展示台相机切独立 `ArtFx_Renderer` 并强制 Depth/Opaque Texture(PandaShader 软粒子/扭曲需要,Mobile RP 默认关)。老模型不带档案,渲染零影响 |
| 模型光照 | 关 | 美术贴图自带最终颜色；上台时只把模型常规 Standard/URP Lit 表面的实例材质切为 URP Unlit，不改资产源材质，不动 Panda/粒子特效材质 |
| 整文件夹导入 | 开 | 角色目录下全部文件入库(不只 GUID 闭包)。FBX 内嵌材质按名搜索的贴图闭包看不见,关了容易白模 |
| 贴图处理 | (已移除) | 压缩/转格式/去重全部拿掉,贴图原样入库;体积问题另行统一处理。之前被压缩过的贴图再点一次 [导入/更新] 会把导入设置还原成美术原样 |
| Addressable 自动分组 | 开 | 等价菜单"神霄/资源/Addressable 自动分组"。**没跑分组=游戏里加载不到(走老模型)** |

## 落位与游戏接线

- `{数字}@动作.prefab` → `Assets/GameRes/object/role/model_create_{数字}/`;角色文件夹外的共享依赖
  (PandaShader、Shared/VFXtexturePack)→ `Assets/GameRes/object/artshared/`,只存一份。
- 创角页(`RoleCreateView.TryShowWholeModel`):探测 `object/role/model_create_{RoleRes}/{RoleRes}@create2`,
  有→整模路径(create2 播完 Hold→切 create3 循环),没有→老拼装链。**只影响已导入的职业,其余照旧。**
- **落点统一规则(终版)**:【出场落点 = 待机位置 = 占位位置】。
  1. **导入时精确采样(权威)**:导入工具把 create3 实例化、`SampleAnimation` 拨到**末帧**、
     BakeMesh 量出精确的脚底中心+身高,**烤进 prefab 的渲染档案**(Console 打
     `[ArtImport] ... 落点采样:landing=... 身高=... scale=...`)。静态包围盒是绑定姿势的松盒,
     和动画停放点不是一回事(1213 曾因此巨腿怼镜头),一律不用。
  2. **运行时只读档案**:整体平移把落点对到占位点+体量归一到老角色身高(2.33);位移原样播、
     不碰 Director。档案里没落点(旧版导入)→原样上台+日志提示重导。
  3. **页面配置只调"台子在屏幕哪里"**:`configlogin.json → CreateRole.ModelPos`(整页)/
     `PosOffset["职业@性别"]`(单职业),x 右正、y 上正,单位=世界单位(全高 12.8≈容器整高,
     0.5≈4% 屏高),改完重启 Play。**不要拿它补单个模型的偏差**。
  4. **美术侧仍建议**:体量对齐老角色(≈2.3,[尺寸参照]工具)、create2 末帧真实站定
     (采样信任末帧姿势)。位置归不归零不再影响精度——采样会精确对准。
  (整模相机=透视 FOV60,深度位移可见;老模型照旧正交。)
- **给美术的展示台坐标契约**(创角整模按此制作,即所见即所得):
  - 待机(create3)脚底站在 **世界原点 (0,0,0)**,朝向与老角色一致(用交付模板的[尺寸参照]对齐);
  - 出场(create2)允许空间位移,**最后落点必须 = 待机位置**(原点);
  - 体量对齐老角色(≈2.3 米):展示台对所有模型统一放大 ×2.75,正交取景全高 12.8,
    即 2.3 米的角色在屏幕上约占半屏高;做太大/太小=直接超框/太小只能回源头改;
  - 展示相机看向 -Z 方向的模型正面(台子会把模型转 180°,和老角色同规则)。
- **亮度/颜色**:选角、游戏内场景模型和资产管理预览均不建灯、不改写
  `RenderSettings.ambientLight`。常规模型表面以 URP Unlit 显示贴图原色；颜色与明暗由美术直接画入贴图，
  程序不再同步或模拟美术场景灯光。PandaShader 粒子/扭曲继续保留自身混合与发光参数。

## 故障排查

| 现象 | 查什么 |
|---|---|
| 模型全白(贴图丢) | 根因(1111 实锤):身体用 **FBX 内嵌材质**,贴图按 FBX 里记录的**美术机文件名/路径搜索**(如 `\男1\新建文件夹\服饰.tga`),GUID 闭包看不见 → 贴图没进工程=白模。修复(已内建,**[导入/更新] 一次即可**):① 整文件夹导入把 Tex/Materials 全量搬入;② 内嵌材质自动换外置:同名 .mat → **同主贴图**的 .mat(内嵌名常是 Max 默认名"21 - Default"对不上,按贴图对)→ 都没有就现生成 URP/Unlit;③ FBX 二次导入兜底 |
| 整体偏黑/发蓝 | 先查运行实例的常规表面是否已切到 `Universal Render Pipeline/Unlit`，再查有色贴图是否真正进入 `_BaseMap`。禁止为了补亮重新加平行光、环境光或预览灯 |
| 特效台上发暗/压黑背景 | PandaShader 的混合因子写 alpha 污染 RT 覆盖度(加法光团把 alpha 加满→合成时把 UI 背景压暗)。修复=shader 加 `[_ScrA][_DstA]` alpha 通道(主工程和美术工程**两份同步改,须保持一致**),导入时按材质自动设:加法族不写 alpha,半透族写覆盖度 |
| 游戏里模型左右镜像 | 展示台为 Laya 老模型做了 RT 水平翻转补偿(老端几何是镜像的);新成品模型是原生朝向,带渲染档案的模型已自动**不翻转**。发现镜像=该 prefab 没挂 ArtModelRenderProfile(重新 [导入/更新]) |
| 模型全紫 | shader 缺/编译失败:确认 `object/artshared/PandaShaderV2.3/` 在,点开 shader 看 Console 报错 |
| 游戏里看不到模型 | 先确认跑过 Addressable 自动分组;归一化已兜底大小/位置,若仍取不到景=该 prefab 没有蒙皮网格(锚点退化),报给程序 |
| 特效在台上洗成白块(场景里正常) | 已修:带渲染档案的模型自动使用独立 Renderer、Depth/Opaque Texture 和 `Shenxiao/UI/StageComposite` 预乘合成；老模型仍走默认路径。若仍异常先确认运行时实际取到 `ArtModelRenderProfile`，再查材质 `_ScrA/_DstA` |
| 一直走老模型 | 地址没登记(跑分组)、或 res id 对不上:职业 role_res 见 configlogin.json 的 CreateRole.Res(1111/1213/1300/1400) |
| 出场动画"原地做动作"(位移不见) | 实锤根因:位移沿 Z(镜头深度),**正交相机下深度移动不可见**;整模已自动切透视 FOV60(照抄美术工程相机,落点平面构图不变)。仍不动→跑诊断菜单看顶层节点(如 ride)逐轴曲线统计,X/Y/Z 全常量=位移根本不在动画里(美术那边看到的是他们场景的相机运动) |
| 该透明的地方渲成白块/半透渐变不对 | 透明信息在贴图 alpha 里,内嵌材质默认 Opaque 不读。**已自动双轨处理**(导入时分析每张贴图的 alpha 直方图并烤进档案,重导生效):二值缺口→Alpha Clipping 镂空;有渐变像素(>0.2%)的材质→Transparent 混合+保深度写(轻纱/飘带柔和渐变)。台账 notes 会点名"半透渐变材质"。美术在 prefab 里自设 Transparent 的材质游戏不碰。若某材质转 Transparent 后出现自身排序瑕疵→把纱类部件拆成独立材质是最优解 |

## 与美术的约定(违反=游戏里出问题)

1. **动作最后一帧 = 模型实际位置/中心**(运行时按此归一化取景);
2. creator 整模只做 create2(展示,单次)+create3(待机,循环),待机首尾衔接;
3. 特效允许原生粒子+PandaShader,但**粒子材质不能有空引用**;贴图 2 的幂,主体 ≤1024;
4. 交付=整个角色文件夹(`role_{ResID}/`),别挑文件拷(历史上丢过整个 VFXtexturePack)。
