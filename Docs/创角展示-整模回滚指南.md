## Android 模拟器花屏边界（2026-07-28）

- 现有 8 段视频已核对为 H.264 Main、yuv420p、720×1280；模拟器 logcat 的失败点是
  `OMX.qcom.video.decoder.avc` 向 `goldfish_vulkan` 输出表面时 `DynamicANWBuffer failed`，不是资源文件损坏。
- 验收顺序固定为：真机播放 → 模拟器切 OpenGL/兼容模式并冷启动 → 再看 logcat。真机正常而模拟器仍花屏时，
  不改视频播放逻辑，也不为模拟器全局调整 Android 图形 API 顺序。
- 后续素材继续采用 H.264/yuv420p 的保守规格；码流兼容与“解码器到虚拟显卡”的表面桥接是两层问题，
  重编码不能修复后者。
