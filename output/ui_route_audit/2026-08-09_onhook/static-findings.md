# OnHook / 挂机完整路线静态核查

## 结论

- 当前 Unity 没有 OnHook 收益页可编辑 Prefab。玩家路线落到 `OnHookShellView` 的 480×330 运行时代码临时壳；老端权威 `OnHookMainView` 是 601×726/866 的完整活动层页面。
- 因此本页必须走 `convert-module` 首次落地，不能把 MainUI 的 `HudOnHook.prefab` 当作收益页面，也不能继续扩写运行时代码建树。
- 本轮禁止 Unity、浏览器、Generated、Addressables 和账号写事务，无法安全完成转换所需的快照、烤制、Bind 回填及注册；已把转换边界登记为 blocker，没有制造假 Prefab。
- 当前 OnHook 协议底座 13211/12/14/15/16/17/18 已存在，但完整页面、13213 找回、奖励结果演出及多个返回链未闭合。

## 静态已证缺口

1. **页面身份错误**：`OnHookShellView` 只有标题、四行摘要、领取、关闭；缺少老端背景、进度、加时、红点、找回区、金币/经验摘要、奖励列表、说明、加成页等。
2. **加成入口断路**：`MainUIOnHookView.OpenAddition()` 请求 13217 后 `MainUIRouter.Open("onhook_addition")`，但 `OnHookBootstrap` 只注册 `onhook`。
3. **找回全链缺失**：13213 未注册、未发送；缺一次/全部、道具库存、自动购绑定/非绑勾玉确认、充值分支、经验奖励与 13212 刷新。该协议按项目硬约束保持 hard-negative。
4. **领取结果降级**：13216 成功只 Toast；老端会映射/排序 `goods_list`、打开 `CongratulationObtainView`、传 `old_lv/old_lv_ratio`，并对货币触发奖励飞行。
5. **主页面状态缺失**：未显示 304px 累计进度、剩余时长、真实金币/经验、详细奖励列表、空态、`<=15h` 加时红点、自动熔炼说明条件。
6. **加成页缺失**：缺 13217 汇总、四种加成项、进度/永久/倒计时/满级状态、VIP/经验符/守护/同修跳转以及经验符获取/使用弹层。
7. **跨 Task 写风险**：`TaskSystemAutoPilot` 对 tips=91 直接调用 `OnHookController.Receive()`，会绕过真实 UI 点击；Task 本轮只读，只登记 blocker。
8. **当前全量编译被外岛阻塞**：仓库并行中的 `AutoBrushController.cs:207,211` 存在 `CS0266 long -> ulong`，不是 OnHook 缺陷；OnHook 两个源文件的隔离编译为 0 errors。

## 老端控件树摘要

- 固定 HUD：显隐门禁、标准/旧版入口、经验效率、加成按钮、静态/扫光/maxed 三态。
- 主页面：背景/标题/关闭；累计挂机进度、剩余时长、经验效率；加时按钮与 `<=15h` 红点；加成按钮；条件找回区；金币/经验摘要；奖励列表/空态；一键领取；自动熔炼提示。
- 找回区：剩余小时、预计经验、经验物品库存、找回 1 小时、找回全部、自动购确认、充值跳转、结果与刷新。
- 加成页：当前加成、世界等级加成、当前效率、世界等级；VIP/经验符/悟道灵宠/剑魄同修四类项目及进度、时间、满级与跳转。
- 经验符弹层：1.5 倍/2 倍物品、持有时使用、缺少时动态获取途径、预计经验、关闭链。
- 结果：成功/失败、奖励弹窗、货币飞行、服务端主动 13212 刷新、任务 91 成功计数。
