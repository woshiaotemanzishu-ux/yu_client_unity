## 本轮分组与抽样

| 分组 | 代表 | 理由 |
|---|---|---|
| 目标页、嵌套展示、特效 on/off | `SuitModule.prefab → EquipSuitPosItem → EquipmentItem` | 本次缺陷目标，验证精确已穿戴实例、阶级、二维流光和清理 |
| 同页展示、特效必须 off | `SuitModule.prefab` 中央当前/下一阶 `EquipmentItem` | 防止槽位能力泄漏到页面展示链 |
| 高频独立页面、交互、有数据/空槽、特效 on/off | `BagEquipmentIcon.prefab → EquipmentItem` | 根组件和生命周期变化的高频代表 |
| 高频独立页面、普通格、有数据/空格、特效 off | `BagModule.prefab → BagItemRenderer → BaseAwardItem` | 直接覆盖本次空灰格回归 |

运行时代码中 `.SetSuitEffect(` 的生产调用点仅有两个：`BagEquipmentIcon.SetData` 与 `ResonancePresenter` 的共鸣边缘部位格。该数量用于证明 opt-in 边界，不代表两条调用已经完成真实像素验收。
