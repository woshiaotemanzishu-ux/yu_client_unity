# TopVip 静态复核修订 v2

本版本保留上级目录 v1 台账，按 schema 6 拓扑不可变规则另建，不原地抬版或改旧树。

## v1 遗漏与修正

- 增补入口拒绝提示和四页签独立红点条件叶。
- `exp_gp` 实际先打开 `AlertTypeTwo`：补齐内容、确认 45106、取消、关闭按钮和背景关闭。
- 永久购买 `buy_gp` 实际先打开 `AlertTypeTwo`：补齐内容、确认 45107、取消、关闭按钮和背景关闭。
- 8 个 `point_gp_0..7` 均打开共享 `TopVipSkillPointView`：保留 8 个入口，并补属性内容、定位和背景关闭链。
- `ShopBulkPurchaseView` 不只是一个交易叶：补商品/消耗详情、限购/价格状态、±1/±10、本地数量、数字键盘、取消/关闭/背景关闭，以及直接 15302、绑元替代确认、快速使用溢出确认、充值和不足提示分支。
- `CalculatorView` 补 0..9 数字键矩阵、退格、确认关闭和背景关闭。
- 精确记录配置矩阵：6 个技能阶段 × 每阶段 8 个任务；13 个特权货币任务；永久 VIP 每日礼包 5 个奖励格。
- 共享批量购买弹窗的关闭按钮有专用 CLOSE 声音；其余页面专属源未发现主动声音调用，通用点击声仍需运行态验证。

## 交易边界

- 45103、45105、45106、45107、45108 均为 R601 hard-negative。
- 15302 单次/批量购买、绑元替代确认、快速使用确认，以及充值导航均未点击。
- v2 的全部 transaction 或 destructive-write 叶均为 `blocked`，`blocked_reason` 显式包含“本轮未点击”。

## 首次落地 blocker

`convert-module` 不能在本轮执行：它要求真实老端运行快照、Unity MCP 串行烤制/回填、注册 Addressables、Unity 编译与运行 diff；本轮禁止 Unity/浏览器且 Addressables 不在文件岛。静态转换器产物不能替代这些门禁。
